## 🎨 Visual Standards

### Image Specifications

- **Format**: PNG for UI screenshots, JPG for collages
- **File Size**: <500 KB (target <200 KB)
- **Resolution**: Minimum 1200px width for desktop screenshots
- **Quality**: High resolution with clear, readable text
- **Compression**: Use TinyPNG or Squoosh for optimization

### Naming Convention

- Use kebab-case (lowercase with hyphens)
- Descriptive names matching functionality
- No spaces or special characters
- Include device type if multiple versions exist

### Screenshot Content Guidelines

- **Professional Data**: Use realistic, anonymized sample data
- **Clean Interface**: Hide development tools and test content
- **Consistent Branding**: Ensure UniBridge logo and colors are visible
- **Privacy Compliance**: Blur any personal information
- **Browser Consistency**: Use same browser/theme for all screenshots

## 📐 Layout Recommendations

### Main README Usage

- **Responsive Grid**: CSS Grid with auto-fit columns
- **Mobile Optimization**: Stack vertically on smaller screens
- **Loading**: Include lazy loading for performance
- **Alt Text**: Descriptive, specific text for accessibility

### Extended Documentation

- **Feature Galleries**: Group related screenshots by functionality
- **Before/After**: Show improvements or user journey progression
- **Multi-Device**: Desktop, tablet, and mobile views
- **User Flows**: Sequential screenshots showing complete workflows
